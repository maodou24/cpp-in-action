## Types

A declaration is a statement that introduces a name into the program. It specifies a type for the
named entity

### Fundamental Types

```text
    bool    // Boolean, true and false
    char    // character, 'a', ' z', and '9'
    int     // integer, 1, 42, and 1066
    float  // floating-point number, 3.14
    double // double-precision floating-point number, 3.14 and 299793.0
    void  // used to signify the absence of information
```
 
using declarator operators

```text
    type*   // pointer, such as int*
    type[]  // array, such as char[]
    type&   // reference, such as double& and vector<int>&&
```
